# Mis Perris 

Proyecto web desarrollado en 2018 durante mi formación en Ingeniería Informática en Duoc UC.
La aplicación corresponde a una página orientada al rescate y adopción de perros, creada como parte de una evaluación académica de desarrollo web.

## Sobre el proyecto

Mis Perris fue uno de mis primeros proyectos de desarrollo web. El objetivo era construir un sitio visualmente estructurado y funcional, aplicando conceptos básicos de desarrollo frontend.
El proyecto incluye distintas secciones informativas relacionadas con rescate y adopción de perros, además de recursos gráficos, estilos personalizados y validaciones realizadas con JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery

## Estructura del proyecto

El repositorio contiene principalmente:

- 'MiPerris.html': página principal del proyecto.
- 'css/': hojas de estilo.
- 'js/': scripts y validaciones.
- 'img/': imágenes utilizadas en el sitio.
- 'logos/': recursos gráficos.
- 'validacion.PNG': evidencia de validación realizada durante la evaluación.

## Contexto

Este proyecto fue desarrollado aproximadamente en 2018 como parte de una evaluación académica en Duoc UC, para el ramo Desarrollo web.
Decidí recuperar y publicar el repositorio original como parte de mi portafolio, manteniendo el proyecto prácticamente en su estado original para reflejar una etapa temprana de mi formación y mi evolución profesional desde entonces.

## Aprendizajes

Este proyecto me permitió comenzar a trabajar con conceptos como:

- Estructuración de páginas utilizando HTML.
- Diseño y estilos con CSS.
- Uso de JavaScript para validaciones e interacción.
- Organización de recursos dentro de un proyecto web.
- Uso de Git y repositorios para almacenar código.
